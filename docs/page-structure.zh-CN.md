# MyTherapy 页面结构方案

## 1. 文档目的

本文件用于定义 MVP 的页面结构，明确每个页面的核心目标、主要模块、用户动作和相邻跳转关系。

本文件用于后续：

- 页面清单确认
- 原型设计
- 前端开发切分
- 测试用例准备

## 2. 页面结构总览

MVP 建议页面分为 5 组：

1. 首次进入与空状态
2. 首页与执行流
3. OCR 导入与确认流
4. 记录与导出流
5. 我的疗程与设置流

## 3. 首次进入与空状态

### 3.1 首次欢迎页

目标：

- 让用户理解产品价值
- 引导用户开始导入医嘱

主要模块：

- 产品标题
- 核心价值一句话
- 主要 CTA：扫描医嘱 / 处方
- 次级 CTA：手动添加药物

主要动作：

- 开始扫描
- 稍后再说

跳转：

- OCR 导入页
- 今日空状态页

### 3.2 今日空状态页

目标：

- 告诉用户当前还没有服药计划
- 给出最明确的下一步

主要模块：

- 插画或空状态图
- 说明文案
- 主按钮：导入医嘱
- 次按钮：手动添加

主要动作：

- 导入医嘱
- 手动添加药物

跳转：

- OCR 导入页
- 药物手动添加页

## 4. 首页与执行流

### 4.1 今日首页

目标：

- 让用户一眼看到今天该做什么

主要模块：

- 顶部标题与状态
- 横向日期条
- 月历触发入口
- 下一次服药卡片
- 今日待完成任务列表
- 已完成任务折叠区
- 风险提醒卡片
- 悬浮新增按钮

主要动作：

- 切换日期
- 查看月历
- 执行服药任务
- 展开已完成任务
- 打开新增菜单

跳转：

- 月历弹层
- 任务详情页
- 快速新增菜单

### 4.2 月历弹层

目标：

- 快速跳转到指定日期

主要模块：

- 当前月份标题
- 上月 / 下月切换
- 日期网格
- 下方当日摘要

主要动作：

- 切换月份
- 选择日期

跳转：

- 返回今日首页并刷新当天数据

### 4.3 任务详情页

目标：

- 展示某一次服药任务的完整信息

主要模块：

- 药名
- 剂量与说明
- 计划时间
- 饭前 / 饭后说明
- 库存信息
- 主要操作按钮

主要动作：

- 标记已服
- 延后
- 跳过

跳转：

- 服药结果页或回到今日首页

### 4.4 快速新增菜单

目标：

- 统一承接新增动作

主要模块：

- 扫描医嘱 / 处方
- 手动添加药物
- 添加指标记录
- 添加副作用记录

## 5. OCR 导入与确认流

### 5.1 导入来源选择页

目标：

- 让用户选择拍照或上传图片

主要模块：

- 拍照入口
- 相册上传入口
- 导入说明

### 5.2 OCR 处理中页

目标：

- 给用户明确反馈
- 降低等待焦虑

主要模块：

- 处理中动画
- 文案说明
- 风险提示：请确认识别结果

### 5.3 OCR 结果确认页

目标：

- 让用户检查 AI 提取内容
- 生成可执行的计划

主要模块：

- 原始图片缩略图
- 药名字段
- 剂量字段
- 频次字段
- 疗程字段
- 特殊备注字段
- 不确定字段提示
- 确认生成按钮

主要动作：

- 修改字段
- 删除字段
- 添加缺失字段
- 确认生成计划

跳转：

- 计划生成成功页
- 今日首页

### 5.4 计划生成成功页

目标：

- 告诉用户计划已创建完成
- 引导回到今日执行

主要模块：

- 成功提示
- 计划摘要
- 去今日查看按钮

## 6. 记录与导出流

### 6.1 记录页 - 概览

目标：

- 用最轻量的方式展示执行表现

主要模块：

- 本周完成率
- 连续完成天数
- 最近副作用摘要
- 最近指标摘要
- 切换到历史视图入口

### 6.2 记录页 - 历史

目标：

- 让用户按时间回看记录

主要模块：

- 日期分组
- 每日记录列表
- 每条记录的计划时间 / 实际时间 / 状态

### 6.3 导出页

目标：

- 生成可带去复诊的资料

主要模块：

- 时间范围选择
- 导出内容选择
- 导出说明
- 导出按钮

## 7. 我的疗程与设置流

### 7.1 我的疗程页

目标：

- 管理药物和其他治疗对象

主要模块：

- 药物分组
- 指标分组
- 副作用 / 症状分组
- 预约分组
- 悬浮新增按钮

### 7.2 药物详情页

目标：

- 查看某个药物的完整计划信息

主要模块：

- 药名
- 频次
- 提醒时间
- 库存状态
- 编辑入口

### 7.3 药物编辑页

目标：

- 修改药物信息和提醒计划

主要模块：

- 基础字段表单
- 提醒时间编辑
- 库存参数设置

### 7.4 设置页

目标：

- 管理系统相关配置

主要模块：

- 个人资料
- 提醒与通知
- 权限状态
- 数据与备份
- 帮助与反馈
- 关于

### 7.5 通知与权限页

目标：

- 明确提醒是否可靠工作

主要模块：

- 通知状态
- 电池限制状态
- 系统权限说明
- 去系统设置按钮

## 8. 页面之间的关键跳转关系

关键主路径：

1. 首次页 -> OCR 导入页
2. OCR 导入页 -> OCR 处理中页
3. OCR 处理中页 -> OCR 结果确认页
4. OCR 结果确认页 -> 计划生成成功页
5. 成功页 -> 今日首页
6. 今日首页 -> 任务详情页
7. 任务详情页 -> 已服 / 延后 / 跳过
8. 今日首页 -> 记录页
9. 今日首页 -> 我的疗程页
10. 今日首页 -> 设置页

## 9. MVP 页面优先级

P0：

- 今日首页
- OCR 导入页
- OCR 确认页
- 任务详情页
- 记录页
- 导出页
- 我的疗程页
- 药物详情页
- 设置页
- 通知与权限页

P1：

- 月历高级交互
- 日历接入页
- 家属协助页
- 帮助聊天页

## 10. 结论

页面结构应围绕“导入 -> 生成计划 -> 今日执行 -> 持续记录 -> 导出复诊资料”这个闭环展开。

只要这个结构成立，后面无论是做原型还是做开发，方向都会稳定很多。
