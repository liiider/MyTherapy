## 关键产品结论

- 单次记录应直达药物录入页，不再先经过分类二次分流。
- 长期规划应先走基础信息页，再进入规则配置流程。
- 单次记录页保留 `按需选择药物` 区块，因为它是“按需药物资产复用”的入口，不是效率型快捷功能。
- 长期基础信息页不保留该区块，避免与长期规则配置职责冲突。
- 按钮方向统一为 `左次右主`（例如：左 `取消`，右 `保存/下一步`）。

## 当前可验链路

### 单次记录链路

- `Today + -> 添加内容 -> 单次记录 -> 药物录入页 -> 保存 -> Today 已完成区`
- 单次记录页字段为：`名称 / 数量(默认1) / 单位 / 日期时间 / 备注`
- 在单次记录页可通过 `按需选择药物` 回填记录信息。

### 长期规划链路

- `Today + -> 添加内容 -> 长期规划 -> 药物 -> 长期基础信息 -> 常规提醒/按需药物`
- 常规提醒链路：`频率 -> 提醒时间 -> 补库存提醒 -> 保存结果`
- 按需药物链路：`保存结果`（进入疗程，不进入今日任务）
